HOW TO INSTALL
Five steps to get up and running with ATLauncher.
1
DOWNLOAD & OPEN ATLAUNCHER

ATLauncher is a free Minecraft launcher with great modpack support. Download it, install it, and log in with your Microsoft / Mojang account before continuing.

↗ GET ATLAUNCHER
2
DOWNLOAD THE MODPACK ZIP

Download the custom build from Google Drive. Save it somewhere easy to find — your Downloads folder is fine. Do NOT unzip it.

⬇ DOWNLOAD MODPACK ZIP
3
IMPORT MODPACK IN ATLAUNCHER

In ATLauncher, open the Instances tab and click Import. You'll see the dialog shown below.

4
BROWSE & SELECT THE ZIP FILE

Click Browse, navigate to where you saved the modpack ZIP, select it, and click Open.

5
INSTALL & CONFIRM

ATLauncher shows the pack details. Click Install, confirm any dialogs, and wait for the installation to finish. Then hit Play — enjoy!
